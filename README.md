Penjelasan<br>
Pada awal program saya menggunakan list kosong:<br>
nama_hewan: Ini untuk menyimpan nama dari hewan peliharaan yang diinput<br>
jenis_hewan: ini untuk menyimpan jenis hewan<br>
status_makan: ini untuk menyimpan status makan hewan<br>
status_minum: ini untuk menyimpan status minum hewan peliharaan<br>
Kemudian masuk pada while True agar program dapat berjalan secara terus menerus tanpa henti. Setiap kali pengguna memilih salah satu menu dari 1-8, alur program tidak akan langsung mati, melainkan otomatis dialihkan kembali ke atas untuk kembali memunculkan menu utama. Program akan berhenti jika kita memilih menu 8.<br>

Saya juga menggunakan .append() untuk memasukkan nama dan jenis hewan yang ingin saya tambahkan ke dalam list.<br>
saya juga menggunakan for untuk menampilkan atau membaca list. Bisa kita lihat setelah kita menambahkan hewan kita bisa memilih menu 1 dan program akan menampilkan output semua hewan yang ada dan pada menu 2 mencari nama saya menggunakan .lower.<br>

Kemudian pada menu 3&4 saya membuat atau mengkonversikan nomor pilihan pengguna menjadi indeks (nomor-1) lalu menyimpannya mejadi nilai status sudah. Pada menu 7 yaitu fitur reset, fitur ini untuk mengatur ulang semua data status makan dan minum yang sudah menjadi belum tnpa menghapus nama dan jenis hewan.<br>
